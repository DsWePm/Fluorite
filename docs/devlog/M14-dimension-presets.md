# M14：维度预设与地狱介质

M14 把维度差异从散落的维度判断整理为版本化 Provider/preset，并完成第一个非大气 Provider：地狱本地光与均匀雾。主世界保持既有物理大气；末地的 HDRI/Kerr 黑洞仍留给独立里程碑。

## 架构与资源所有权

`RtSkyPreset` 从 `assets/fluorite/fluorite/sky/<namespace>/<dimension>.json` 加载。资源包可覆盖内置 preset；加载器校验 format、有限值、范围和介质能量关系，并逐文件隔离错误。未知、缺失或无效的模组维度回退到完整物理大气，不根据 `dimensionType()` 猜环境。

参数顺序固定为：preset 基础值 → preset 允许的时间/天气 forcing → 用户全局修正 → 玩家逐维度修正。shader 只读取 `SkyProvider` 与能力标志，不接触维度 ID。`skyProvider/environmentFlags` 使用 `WorldPush` 既有 8 B padding，结构仍为 944 B。

大气 Provider 继续运行 transmittance、multi-scatter、sky-view、reduction 与 froxel 链。非大气 Provider 跳过无意义的大气 bake；资源包若给非大气维度启用云或结构雾，当前仍会为共享静态纹理生命周期执行一次 bake，只有实测加载成本值得时再拆。

## 地狱 Provider

地狱关闭太阳、月亮、Rayleigh/Mie/臭氧、程序星空、云和天气 forcing。本地熔岩、萤石等发光体使用 RT 与 froxel 共用的 `light_sampling.slang` Light/alias/grid 接口；froxel 每个样本做一次局部发光体 NEE 和阴影线，没有复制第二套光源格式。

环境介质是关闭噪声的均匀白雾。另有 D78A 批准的极低中性白可读性保底光：它不受遮挡，只进入漫反射、逃逸背景与介质环境源，不伪造镜面环境。这个近似明确服务于可读性，不宣称物理准确。

“维度设置”只控制精确的 `minecraft:the_nether`：

- 地狱雾开关；全局体积雾仍是总开关。
- 地狱雾浓度倍率 `0–2`，默认 `1`；它与全局雾倍率合并后的最终玩家增益仍夹在 2。
- 地狱环境光倍率 `0–8`，默认 `1`；统一缩放保底光、逃逸背景和雾/水环境源，不改变局部发光体功率。
- 末地只保留人类可见的空分组，不发布无效旋钮。

## DLSS-RR 浓雾边界

视觉验收发现：地狱雾倍率很高时，DLSS Ray Reconstruction 会把远处白色表面重建成绿色；靠近后恢复。把环境光提高到 `8×` 不改变绿色，降低雾浓度则立即恢复，因而排除了“中性环境基线过低”。这确认了高密度远景体积与当前 RR 路径的行为边界，但没有进一步声称问题位于 RR 模型本身还是其低覆盖率 guide 输入。

产品裁决是把逐维度地狱雾倍率限制为 `0–2`，并把全局与地狱倍率合并后的最终玩家增益夹在 2。限制同时存在于配置值域、UI 和最终参数解析：旧 TOML、系统属性或运行时写入超过 2 都会被夹到 2，界面也不会显示无法生效的更高值，全局倍率也不能从旁路重新越过边界。这是当前 RR 兼容性边界，不是物理介质的理论上限；升级 RR/驱动或重做 guide 后可用同一远近白色表面用例重新评估。

## 验收与验证

游戏内确认了地狱不残留地球大气、天体、云或天气响应；均匀雾可被本地发光体染色并正确受遮挡；逐维度雾和环境光控制不泄漏到主世界。高密度远景绿色通过 `0–2` 上限隔离。

代码侧通过：

- 全量 Slang shader 编译。
- preset 加载/回退、WorldPush ABI 与逐维度控制测试。
- Fabric 和 NeoForge 完整测试与构建。

## 后续末地路线

末地使用全方向 CC0 star HDRI，不使用地球大气、日月、云或体积雾。黑洞影响区由构建期固定 Kerr 参数预计算 transfer LUT，运行时弯折方向采样同一 HDRI，再以 `Tdisk·background + Ldisk` 合成光学厚吸积盘；与亮盘方向一致的有限面积遥远光源复用天体 NEE。不得退化成一张难以对齐的黑洞贴图。
