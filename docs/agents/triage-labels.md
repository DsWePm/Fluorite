# 问题状态标签

下表是诊断和任务分流使用的状态标签。它们描述“接下来由谁做什么”，可以与 `bug`、`enhancement`、`documentation` 等内容类型标签并存。

| 状态角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| 待评估 | `needs-triage` | 维护者需要判断范围、优先级和证据是否充分 |
| 等待信息 | `needs-info` | 需要报告者补充复现条件、日志或选择 |
| 可交给 agent | `ready-for-agent` | 规格和边界已经完整，可在无人补充上下文时执行 |
| 需要人工处理 | `ready-for-human` | 必须由人类进行视觉判断、交互操作或方向裁决 |
| 不处理 | `wontfix` | 已决定不继续处理，并应说明原因 |

使用这些标签时，应先移除与新状态冲突的旧状态标签，避免一个 Issue 同时显示两个互斥的下一步。
